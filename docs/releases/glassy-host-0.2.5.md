Adds support for Paste to Mac in compatible Glassy Desk iPhone and iPad builds. Copy text on your device, then use Paste to Mac or Cmd-V while the remote desktop has focus to paste into the active Mac app. Requires Fast Connection.

Supports multiline text, emoji, and other Unicode characters, with up to 1 MB per paste. Clipboard transfer happens only when you paste, using the existing encrypted connection and native iOS paste actions to avoid repeated clipboard permission prompts.
